# INXMD Lookbook

Responsive static lookbook page for the 30 generated portraits in `images/`.

## Interaction

- Drag one portrait onto another to swap their positions.
- On touch devices, drag with a finger or select two tiles with a tap.
- Keyboard users can select with `Enter` or `Space` and move a selected tile with the arrow keys.
- `Shuffle` randomizes the current order; `Reset` restores the initial order.

Open `index.html` directly in a browser, or serve the folder with any static file server.
